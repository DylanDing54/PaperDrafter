# ACM SIGCONF

Official acmart v2.21 (2026-11-01), obtained from the TeX Live package and documentation archives distributed on CTAN. The official sigconf.tex is provided unchanged as main.tex, with its bibliography, figures, class and BibTeX style. The docstrip sources and upstream license information are in upstream-sources.zip.

- https://mirrors.ctan.org/systems/texlive/tlnet/archive/acmart.doc.tar.xz
